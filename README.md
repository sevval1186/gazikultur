# GaziKültür

GaziKültür, Gaziantep'in kültürel mirasını ve müzelerini tanıtmak amacıyla geliştirilmiş bir ASP.NET Core MVC web uygulamasıdır.

Proje, kullanıcıların Gaziantep'teki müzeler hakkında bilgi edinmesini ve müzelerin detaylarına kolayca ulaşmasını sağlamayı amaçlamaktadır.

## Projenin Amacı

Bu proje staj kapsamında geliştirilmiştir.

GaziKültür ile kullanıcılar:

- Gaziantep'teki müzeleri görüntüleyebilir.
- Müze detaylarını inceleyebilir.
- Müze adreslerine ulaşabilir.
- Ziyaret günleri ve saatlerini görebilir.
- Giriş ücretleri hakkında bilgi alabilir.
- Müzelere ait fotoğrafları görüntüleyebilir.
- Harita bağlantıları üzerinden konum bilgisine ulaşabilir.

- C#

- Microsoft SQL Server

- CSS
- Bootstrap

- `GaziKultur.Core`

- `GaziKultur.Entity`
- `GaziKultur.Service`
- `GaziKultur.Web`

## Admin Paneli

Projede müze bilgilerinin yönetilebilmesi için bir admin paneli bulunmaktadır.

Admin paneli üzerinden:

- Yeni müze ekleme
- Müze bilgilerini güncelleme
- Müze silme

işlemleri gerçekleştirilebilir.

## Veritabanı

Projede Microsoft SQL Server kullanılmaktadır.

Veritabanı işlemleri Entity Framework Core ile gerçekleştirilmiştir.
